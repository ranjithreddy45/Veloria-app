# Day-of Crisis Escalation Sheet — Veloria Grand

What to do when something breaks on event day. **Act first, then log it in the app.**
Fill in **[names / numbers]** once and print this for the ops desk.

## Chain of command
1. **Person on the task** → fix if you can in < 5 min.
2. **Event Coordinator** *[name / phone]* → coordination, client-facing, vendor issues.
3. **Ops Head** *[name / phone]* → resources, money, go/no-go, anything cross-team.
4. **Owner / Director** *[name / phone]* → only for safety, large money, or reputational risk.

> Golden rules: **guest safety first**, **never improvise a refund/discount on the floor** (Ops Head decides), and **log every incident** in the app so it's visible and tracked.

---

## Scenario → action → escalate

| What broke | Do this NOW | Escalate to | Fallback |
|---|---|---|---|
| **Vendor hasn't arrived / is late** | Call the vendor *[from the vendor list]*. Check their confirm status in the app. | Event Coordinator → Ops Head if no ETA within 30 min | Re-task in-house team to cover; Ops Head approves a backup vendor |
| **A task has no owner** (orphaned) / owner is absent | Reassign it on `/bookings/<id>/execution` to anyone free on that team | Ops Head if no one is available for that role | Ops Head pulls someone off a lower-priority task |
| **Food / kitchen delay** | Kitchen lead gives a revised time. Coordinator stalls the timeline (extend welcome drinks / programme). | Ops Head | Serve in courses / adjust the run-of-show; brief service staff |
| **AV / sound / lighting failure** | AV/Operations runs the backup kit; restart the check. | Ops Head if not fixed in 15 min | Acoustic / manual mode; vendor AV if contracted |
| **Decor not ready at cue time** | Coordinator + decor team prioritise the guest-visible areas first. | Ops Head | Delay the reveal; move the cue later on the cockpit timeline |
| **Guest count surges** beyond plan | Confirm the real number with the host. Kitchen + seating assess. | Ops Head (food/cost call) | Pull buffer stock; Ops Head authorises top-up procurement |
| **Payment / billing dispute on the floor** | Stay calm, do **not** settle it there. Note what's claimed. | **Ops Head only** — never refund/discount on the floor | Ops Head reviews in the system after the event |
| **The app / cockpit is down** | Switch to the **printed function sheet (BEO)** + this sheet. Keep working from the BEO. | Ops Head | Run the event off the BEO; re-enter status in the app once it's back |
| **Safety / medical / security incident** | **People first** — secure the area, first aid, call emergency services *[112]* if needed. | **Owner/Director immediately** | Follow venue safety protocol; log a full incident report after |
| **Weather / power / venue issue** | Move to the contingency plan in the BEO (indoor backup, generator). | Ops Head → Owner if major | Venue's backup power / indoor space |
| **Client is unhappy in the moment** | Coordinator listens, acknowledges, offers a fix within scope. | Ops Head for anything involving money or a major change | Recover the experience now; debrief with the client after |

---

## When to call go / no-go
Only the **Ops Head** (or Owner) calls it. Trigger a huddle if:
- A **required readiness gate** is still red at T-2h, **or**
- A **safety** issue can't be resolved, **or**
- A core vendor (catering / venue / power) **can't deliver**.

Decision: **proceed**, **proceed with a documented workaround**, or **delay the start** (notify the host). Record the call + reason as an incident.

---

## After every event (5 min)
- Close out open tasks + log any incidents you didn't capture live.
- Note one thing that went wrong and one fix → feed it into the SOP template so the next event is better.
- Confirm equipment returned + final billing reconciled.
