# Phase 00: UI Pattern Inventory

## 1. Standard UI Design Patterns
1. **Glassmorphism Chrome**: Translucent header and sidebar surfaces with backdrop-blur (`backdrop-blur-md`, `bg-material-sidebar`).
2. **Right-Edge Active Accent**: Active navigation links highlighted with `.sidebar-active-accent` right-edge accent bar.
3. **Stat Card Grids**: Top-level KPI overview grids displaying numeric value, percentage change trend, and Lucide icon.
4. **Data Table Filter Toolbars**: Standard search input + multi-select status dropdowns + date range picker + CSV export button.
5. **Read-Only Lock Banners**: Yellow/Amber alert banners on locked entities (`isLocked = true`) preventing unauthorized edits.
6. **Maker-Checker Approval Badges**: Dual-user verification tags indicating creator vs approver IDs.
7. **Fixed 30-Day Payroll Calculator Cards**: Explicit breakdown cards showing base salary, LOP days subtracted, and net payout.
