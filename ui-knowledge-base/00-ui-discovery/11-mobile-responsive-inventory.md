# Phase 00: Mobile & Responsive UI Inventory

## 1. Mobile & Hybrid Features
- **Responsive Drawer**: AppSidebar converts to slide-out Sheet drawer on screen width `< 768px` (`<md`).
- **Capacitor 8.1 Integration**: Hybrid wrapper support for iOS/Android native shell rendering.
- **Touch-Optimized Signature Pad**: HTML5 canvas signature pad configured for touch events (`onTouchStart`, `onTouchMove`).
