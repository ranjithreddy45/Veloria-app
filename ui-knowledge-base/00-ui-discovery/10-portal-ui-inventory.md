# Phase 00: Portal UI Inventory

## 1. Dedicated Portal Interfaces
- **Client Portal (`/portal/*`)**: Client dashboard, quote viewer, contract viewer, invoice pay portal, seating chart builder.
- **Vendor Portal (`/vendor-portal/*`)**: Vendor dashboard, bid submission, work order viewer, AP bill submission.
- **Employee Self-Service (`/me/*`)**: Personal attendance, leave requests, salary payslips, reimbursement claims, handbook.
- **Public Token Experiences**: `/q/[token]` (Quotes), `/sign/[token]` (Contracts), `/pay/[token]` (Payments), `/hold/[token]` (Venue Holds).
