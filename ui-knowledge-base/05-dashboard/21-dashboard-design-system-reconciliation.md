# DASHBOARD DESIGN SYSTEM RECONCILIATION

## 1. Design Tokens & Component Alignment

Reconciling Dashboard UI against **Phase 01 — Design System** (`ui-knowledge-base/01-design-system/`).

- **Color Tokens**:
  - Background: `bg-background` (Light / Dark mode compatible)
  - Cards: `bg-card` with `border-border/60`
  - Success Indicator: `bg-success` (Pulsing live activity dot)
  - Warning Status: `bg-warning/15` (Degraded data notification)
- **Typography**:
  - Salutation: `text-h2 sm:text-h1 font-bold`
  - Subtitle: `text-meta font-semibold uppercase tracking-[0.1em]`
  - Body Text: `text-copy text-foreground/75`
- **Cards & Spacing**: Standard 16px (`gap-4`) spacing grid with `rounded-[13px]` cards.
