# Phase 01: Spacing & Sizing System

## 1. Spacing Conventions
- **Page Container Padding**: `p-6` (24px) or `p-8` (32px) on desktop, `p-4` (16px) on mobile.
- **Card Content Padding**: `p-6` or `p-4`.
- **Grid Gaps**: `gap-4` (16px) or `gap-6` (24px).
- **Form Row Gaps**: `space-y-4` or `space-y-6`.

## 2. Standard Component Sizing
- **Button Height**: `h-10` (default 40px), `h-9` (sm 36px), `h-11` (lg 44px), `h-8` (xs 32px).
- **Input Height**: `h-10` (40px).
- **Sidebar Width**: `w-64` (256px expanded), `w-16` (64px collapsed).
- **Header Height**: `h-16` (64px).
