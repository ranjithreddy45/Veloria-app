# Phase 01: Typography System

## 1. Font Family & Hierarchy
- **Font Stack**: Modern system sans-serif font stack with Inter / Outfit fallback.
- **Headings**:
  - `h1`: `text-3xl font-bold tracking-tight` (Page Titles)
  - `h2`: `text-2xl font-semibold tracking-tight` (Section Headers)
  - `h3`: `text-xl font-semibold` (Card Titles)
  - `h4`: `text-lg font-medium` (Sub-headers)
- **Body & Controls**:
  - Body: `text-sm text-foreground`
  - Muted: `text-sm text-muted-foreground`
  - Caption: `text-xs text-muted-foreground`
  - Monospace (Money/IDs): `font-mono text-xs font-semibold`
