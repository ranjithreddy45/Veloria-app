# Phase 08: Form Control System

## 1. Form Components (`src/components/ui/*`)
- **Input (`input.tsx`)**: Text, number, email, date input with `h-10 rounded-md border border-input`.
- **Select (`select.tsx`)**: Radix Select wrapper for single selection.
- **Checkbox (`checkbox.tsx`)**: Radix Checkbox with check icon animation.
- **Switch (`switch.tsx`)**: Toggle switch for boolean configurations.
- **Date Picker (`calendar.tsx` & `popover.tsx`)**: DayPicker calendar inside Popover trigger.
- **Textarea (`textarea.tsx`)**: Multi-line text field.
