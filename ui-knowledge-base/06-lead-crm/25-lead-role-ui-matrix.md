# LEAD ROLE UI MATRIX

## 1. Role Customization Matrix

| Role | Visible Leads | Editable Fields | Allowed Actions |
|---|---|---|---|
| **`SALES`** | Assigned Leads Only | Status, Notes, Tasks, Visits | Edit, Create Quote, Schedule Visit |
| **`ADMIN`** | All Venue Leads | All Fields | Full Edit, Delete, Bulk Assign, Import |
| **`GENERAL_MANAGER`** | All Venue Leads | All Fields | Full Edit, Re-assign, Export |
| **`BD`** | Acquisition Leads | BD Notes & Pipeline | BD Specific Follow-ups |
