# Phase 02: Page Header System

## 1. PageHeader Component (`src/components/layout/page-header.tsx`)
- Standardized sub-header pattern across dashboard screens:
  - `Title`: `text-2xl font-bold tracking-tight text-foreground`.
  - `Description`: `text-sm text-muted-foreground`.
  - `Actions`: `flex items-center space-x-2` for CTA buttons (e.g. "Create New", "Export CSV").
