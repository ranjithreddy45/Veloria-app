# 10 - BEO Event Details & Specs

---

## 📝 Event Specification Structure

A BEO function sheet captures complete event execution parameters:
- **Event Name & Category**: E.g., "Mehta Wedding Reception" (Category: `WEDDING`).
- **Time Slot & Timings**: `MORNING` / `EVENING` / `FULL_DAY`, with exact hall access times.
- **Host Details**: Host name, primary phone, email, and on-site contact representative.
- **Sales & Ops Leads**: Assigned Sales Executive name and lead Event Coordinator name.
