# Authentication Routes (5 Endpoints)

## Overview

Authentication routes (`(auth)` / `/login`, `/register`, etc.) manage user login, password recovery, and multi-factor verification.

---

## Auth Endpoints

- **`/login`**: Staff, Client, and Vendor sign-in page.
- **`/register`**: Client account creation page.
- **`/forgot-password`**: Password reset link requester.
- **`/reset-password`**: Password reset token submission page.
- **`/verify-email`**: Email confirmation endpoint.
