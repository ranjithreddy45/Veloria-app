# 07 Leave Types & Configuration

## Standard Seeded Leave Types (`seedLeaveSetup`)

- `CL` (Casual Leave): Paid = true, Accrual = 12 days/year.
- `SL` (Sick Leave): Paid = true, Accrual = 12 days/year.
- `EL` (Earned / Privilege Leave): Paid = true, Accrual = 15 days/year, Carry Forward Max = 30 days.
- `LOP` (Loss of Pay): Paid = false, Accrual = 0, Allow Negative = true.
- `COMP` (Compensatory Off): Paid = true, Accrual = 0 (earned via weekend/event work).
