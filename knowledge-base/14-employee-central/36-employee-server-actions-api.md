# 36 Employee Server Actions & API Inventory

- `hr-employee.actions.ts`: CRUD for employee master.
- `hr-config.actions.ts`: Departments & designations.
- `hr-documents.actions.ts`: Document uploads.
- `hr-statutory.actions.ts`: PAN/Aadhaar/Bank details.
- `hr-compensation.actions.ts`: CTC & salary components.
- `recruit-hire.actions.ts`: Hired candidate conversion.
