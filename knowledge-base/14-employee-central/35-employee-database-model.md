# 35 Complete Employee Database Schema

## Core Schema Models

- `Employee`: Main employee profile.
- `Department`: Organizational unit.
- `HrDesignation`: Job designation.
- `EmployeeStatutory`: PAN, Aadhaar, Bank details.
- `EmployeeEducation`: Academic background.
- `EmployeeWorkHistory`: Prior experience.
- `EmployeeChangeRequest`: Pending profile edits.
- `HrDocument`: File attachments.
